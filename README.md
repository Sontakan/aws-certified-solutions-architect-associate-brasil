# AWS Solutions Architect Brasil

Hub em PT-BR para estudo de arquitetura AWS com foco no exame SAA-C03, visão prática de decisões arquiteturais e revisão rápida por domínio. Este repositório organiza a jornada em módulos, laboratórios leves, materiais de revisão e trilhas de reforço para acelerar consistência de estudo.

## Visão Geral da Jornada

- Fundamentos de arquitetura e leitura do blueprint do exame.
- Segurança, identidade e governança como base de qualquer workload.
- Compute, armazenamento, redes, bancos de dados e integração.
- Operação, observabilidade, continuidade e otimização de custos.
- Revisão final com questões, flashcards e mini simulados.

## Como Usar Este Repositório

1. Siga os módulos numerados para construir base técnica progressiva.
2. Use `cheatsheet.md` e `flashcards.md` para revisão curta diária.
3. Execute os labs como demonstrações guiadas de arquitetura.
4. Registre erros recorrentes em revisões e volte ao módulo correspondente.

## Padrão de Cada Módulo

- `README.md`: contexto do serviço e padrões arquiteturais essenciais.
- `casos-de-uso.md`: cenários comuns de decisão em arquitetura.
- `cheatsheet.md`: resumo de conceitos de alta recorrência.
- `flashcards.md`: perguntas curtas para memorização ativa.
- `questoes.md`: treino direcionado por domínio.
- `lab.md`: prática rápida com foco em entendimento de fluxo.
- `links.md`: referências selecionadas para aprofundamento.

## Trilha Recomendada

- Iniciante: 01 a 10 + labs introdutórios.
- Intermediário: 11 a 20 + revisão por domínio.
- Finalização: 21 a 31 + simulados e caderno de erros.

## Direcionamento de Estudo

- Priorize clareza de trade-off: custo, desempenho, segurança e operação.
- Treine escolha de serviços por padrão arquitetural, não por memorização isolada.
- Revise semanalmente os tópicos com maior taxa de erro.

Contribuições são bem-vindas para melhorar exemplos, corrigir conteúdo e ampliar materiais de revisão em PT-BR para a comunidade AWS brasileira.
